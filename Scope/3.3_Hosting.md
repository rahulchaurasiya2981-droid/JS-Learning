Hoisting|
----------
- Hoisting is the process where JavaScript `allocates memory` for variables and functions during the creation phase, `moving their declarations` to the `top` of their scope. However, only var is initialized with undefined, while let and const remain in the Temporal Dead Zone and functionn is fully hoisted with function body.
- Only declarations are hoisted (during creation phase), not initializations (happen at execution phase)
- `var` = hoisted + initialized (undefined) (we can)
- `let/const` = hoisted but NOT initialized (TDZ)

TDZ
----
- TDZ stands for Temporal Dead Zone.
- TDZ is the `time between` entering a scope `(during creation phase)` and initializing a let or const variable `(during execution phase)`, during which the variable cannot be accessed.
- During TDZ, the variable exists (hoisted) but is uninitialized, so accessing it throws a ReferenceError.

```js
console.log("Hello 1 : ",name);
var name;
name = "raj";
console.log("Hello 2 : ",name);

// Output:
// Hello 1 :  undefined
// Hello 2 :  raj
```

```js
console.log("Hello 1 : ",name);
let name;
name = "raj";
console.log("Hello 2 : ",name);

// Output:
// console.log("hell : ",name);
// ReferenceError: Cannot access 'name' before initialization
```

```js
console.log("Hello 1 : ",name);
const name;
name = "raj";
console.log("Hello 2 : ",name);

// Output:
// const name;
// SyntaxError: Missing initializer in const declaration
```

```js
console.log("Hello 1 : ",name);
const name = "raj";
console.log("Hello 2 : ",name);

// Output:
// console.log("Hello 1 : ",name);
// ReferenceError: Cannot access 'name' before initialization
```
