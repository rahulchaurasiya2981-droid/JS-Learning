Working of js
---------------

1. Execution context
---------------------
- Everthing in js happens inside an `Execution context`
- Execution Context is the environment in which JavaScript code is evaluated and executed
- Two phases : 
    A. Memory creation phase (variable environment)(memory component)
        - Store in `key : value` formate (variable and functions)
    B. Code execution phase (thread of execution)(code component)
        - containe whole js code
        - execure one command at a time in specific order so we called the js is `synchronous single-threaded` language.
