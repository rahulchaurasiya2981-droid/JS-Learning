Call Stack 
-----------
- Call stack manages execution contexts using LIFO to track function calls and execution order.
- Call Stack is a `stack data structure` that manage and keeps track of execution contexts.
- Whenever a function is `invoked`, it is `pushed` onto the stack, and once `execution is completed`, it is `popped off`, following the `LIFO` principle.

1. Create the GEC and FEC with CP and EP flow (for understanding lexical environment)
2. Create stack and heap flow
3. create the stack diagram (for each phase)

```js
console.log("Inside Global Execution context");
var a=5;
function testMe()
{
    console.log("Inside testMe execution context");
    var b=10;
    var name ={
        name:"tapas",
        country:"India"
    }
    function testAgain()
    {
        console.log("Inside testAgain execution context");
        console.log("Existing testAgain execution context");
    }
    testAgain();
    console.log("Existing testMe execution context");
}
testMe();
console.log("Existing global execution context");
```
